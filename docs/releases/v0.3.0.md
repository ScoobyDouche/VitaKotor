# VitaKotor v0.3.0 — long sessions hold up

This is the first build worth starting a real playthrough on. Sessions of about 90 minutes now end as healthy as they started: the sound no longer fades away and the world no longer comes apart into spikes. Keep saving regularly all the same.

## What changed

- **Sound no longer thins out and goes silent.** The game has 45 sound slots and only frees one when it sees the sound finish. Some never got that signal, so after an hour or so every slot was taken, new sounds went nowhere, and the music kept retrying until the game dropped to 5 fps. Dead slots are now handed back. An 87-minute session stayed clean.

- **The world no longer tears into long spikes after 20–40 minutes.** The GPU's pool for vertex shaders filled up and new shaders quietly failed, so models were drawn with the wrong one. The pool is four times larger and frees idle entries when it runs short. An 83-minute session had no failures.

- **Footsteps, doors and containers are at full volume again.** If you played an early build, your `swkotor.ini` holds `2D3D Bias=0.10`, which plays every positioned sound at a tenth of its volume. The loader now resets it to the game's default of 1.00 when it starts, so you don't need to edit anything.

## Honest limits

- **Frame drops.** Normal play runs at 30–37 fps and busy scenes dip to around 20. Some areas also stutter about once a second, and that time goes on the game's own update rather than drawing. It is the next thing being worked on.

- **Loading screens are long.** The area itself loads in under a second, but the loading screen then stays up for 15–20 seconds while textures are uploaded. The game is already running underneath, so the new area's sounds and conversations can start before you see it.

- **A voice line can play over the loading screen after you die and reload.** It was seen once. This build logs enough to find out why, so if it happens to you, please send the log.

- **Some shiny armour looks off.** Sith armour in particular can shine too strongly or with a colour tint.

- **Distant sounds may still be too loud,** and there are no trophies.

## Everything else from v0.2.1 still applies

Fan translations can be picked from the language list. Cutscenes play, the buttons and the touchscreen both work, and combat, dialogue, inventory, saves, the swoop race and Force powers all work.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own.

## Something broken?

Open an issue with `ux0:data/kotor/log.txt` attached.
