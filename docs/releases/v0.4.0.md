# VitaKotor v0.4.0 — mods, and a MODS button to switch them

Mod support comes to the main release, with a MODS button on the main menu for switching between mod setups. Also in: fixes for sound dying after an area change, long freezes when leaving an area, and the sticks.

## What changed

- **Mods load from the memory card.** Put a mod's files in `ux0:data/kotor/override/`, `modules/`, `lips/` or `streamwaves/` and they replace the game's own. You don't need to repack or edit the OBBs. The README's **Mods** section has the folder layout.

- **The Google Play button is now MODS.** Keep several mod setups as folders in `ux0:data/kotor/mods/`, press MODS on the main menu, and the game restarts into a list to pick from. **VANILLA** is always first. Saves are shared between sets.

- **Sound no longer dies after leaving an area.** A sound still loading in the background could be freed underneath its loader, which crashed the sound thread and left the game silent.

- **Leaving an area no longer freezes for seconds.** The area's state was saved to the card in about a thousand tiny writes; it now goes in large blocks, and those frames are about half as long. Large mods were hit hardest.

- **A modded talk table no longer freezes combat.** A card `tv_dialog.tlk` is now read into memory once instead of one line at a time. Fan translations get the same fix.

- **The sticks work after typing a name.** The on-screen keyboard left the controller in digital mode until you restarted.

- **Stick flicker with reVita is filtered.** A single-frame drop to centre while a stick is held is now ignored.

- **The log no longer writes from the game's thread.** It used to write to the card in the middle of about half of the once-a-second stutters; it now has a thread of its own.

- **KOTOR-nolog.vpk**: an optional build with diagnostic logging disabled. Install it in place of `KOTOR.vpk` if you prefer not to have a log file written.

## Updating

Install `KOTOR.vpk` over your current one. Your files in `ux0:data/kotor/` and your saves stay as they are, and mods you already put in the top folder keep working under VANILLA.

## Honest limits

- **Installer mods (TSLPatcher / HoloPatcher) need a PC.** Run the installer on a PC copy of KOTOR 1.03, then copy the results across. A mod's `dialog.tlk` goes in as `tv_dialog.tlk`. Patching a PC install this way is untested.

- **Mods that patch `swkotor.exe` can't work.** That rules out widescreen and high-resolution menu patches and 4 GB patches.

- **Untested:** `.dds` textures, replacement movies, and stacking several installer mods.

- **A save made with a mod may not load properly without it.** Saves are shared between mod sets, so switch with that in mind.

- **Busy areas still run at around 20 fps,** and Sith armour can still turn a bright solid colour.

## Everything else from v0.3.1 still applies

Sounds no longer hitch the game, the sticks work with reVita, and long sessions hold up.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own. Mods come from their own authors; none are included here.

## Something broken?

Open an issue with `ux0:data/kotor/log.txt` attached, and name the mods you have installed and their versions.
