# VitaKotor v0.3.1-mods.1 — mod support preview

A preview build for playing KOTOR with mods. It is v0.3.1 plus mod support and two stick fixes. If you don't use mods, stay on v0.3.1.

## What changed

- **Mods load from the memory card.** Put a mod's files in `ux0:data/kotor/override/`, `modules/`, `lips/` or `streamwaves/` and they replace the game's own. You don't need to repack or edit the OBBs. The README's new **Mods** section has the folder layout.

- **A modded talk table no longer freezes combat.** A mod's `tv_dialog.tlk` was read from the card one line at a time, and fights stalled for a third of a second at a time. The table is now read into memory once. Fan translations get the same fix.

- **The sticks work after typing a name.** The on-screen keyboard left the controller in digital mode, so both sticks read as centred after character creation until you restarted.

- **Stick flicker with reVita is filtered.** A single-frame drop to centre while a stick is held is now ignored.

- **KOTOR-nolog.vpk**: an optional build with diagnostic logging disabled. Install it in place of `KOTOR.vpk` if you prefer not to have a log file written.

## What has been tested

- Loose files in `override/` (textures, 2DA tables) replace the game's, including files inside its texture packs and data archives.

- `.mod` files in `modules/` replace the game's own version of that area.

- **KOTOR 1 Restoration 1.2**, all options, played through its first areas.

## Honest limits

- **Installer mods (TSLPatcher / HoloPatcher) need a PC.** Run the installer on a PC copy of KOTOR 1.03, then copy the results across. A mod's `dialog.tlk` goes at the top of `ux0:data/kotor/`, renamed to `tv_dialog.tlk`. Patching a PC install this way is untested.

- **Mods that patch `swkotor.exe` can't work.** That rules out widescreen and high-resolution menu patches and 4 GB patches.

- **Untested:** `.dds` textures, replacement movies, and stacking several installer mods.

- Start a new game after installing a mod that changes areas or the story.

## Everything else from v0.3.1 still applies

Sounds no longer hitch the game, the sticks work with reVita, and long sessions hold up. The limits listed for v0.3.1 still apply too: busy areas run near 20 fps, and Sith armour can turn a solid colour.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own. Mods come from their own authors; none are included here.

## Something broken?

Open an issue with `ux0:data/kotor/log.txt` attached, and name the mods you have installed and their versions.
