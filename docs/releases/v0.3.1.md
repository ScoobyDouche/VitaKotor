# VitaKotor v0.3.1 — smoother sound, reVita fixed

A fixes release: sounds no longer hitch the game when they start, the sticks work with reVita installed, a crash on area loads is gone, and drawing got a little cheaper.

## What changed

- **No more one-second hitch when a sound starts.** Voice lines were decoded in full before they played, ambient loops were decompressed again every time, and long music tracks were read in one go. Voice lines now stream, ambient sounds are cached, and music loads in the background. On Taris the hitches fell by about half.

- **The sticks work with reVita installed.** reVita turns the rear touchpad back on whenever it reads the controller, so the fingers holding the back of the Vita reached the game as screen drags and the sticks stopped responding. The port no longer reads the rear touchpad.

- **A freeze ending in a crash on an area load is fixed.** The heap had plenty of memory free but no single piece large enough for one request. Requests it refuses are now served from the pool kept for large blocks.

- **Drawing is about 25% cheaper per object.** Every draw asked the graphics library to rebuild a shader setup it already had. Those requests are now answered from a cache, which is worth a few frames a second in a crowd.

- **New LiveArea.** Revan and Bastila on a starfield, with the README now showing screenshots.

- **KOTOR-nolog.vpk**: an optional build with diagnostic logging disabled. Install it in place of `KOTOR.vpk` if you prefer not to have a log file written.

## Honest limits

- **Busy areas run at around 20 fps.** The Lower City holds about 40 fps; the Upper City and the Undercity sit near 20 with a crowd on screen. Almost all of that time is the game's own rendering code on one CPU core, so a faster clock helps less than you would expect.

- **Sith armour can turn a bright solid colour,** green has been seen, and it can change from one area to the next. Each area loads its own reflection maps, and which of them goes wrong is being traced.

- **A voice line can play over the loading screen after you die and reload.** It has been seen once.

- **Distant sounds may still be too loud,** and there are no trophies.

## Everything else from v0.3.0 still applies

Long sessions hold up: sound no longer fades out and the world no longer tears into spikes. Fan translations can be picked from the language list. Cutscenes play, the buttons and the touchscreen both work, and combat, dialogue, inventory, saves, the swoop race and Force powers all work.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own.
