# VitaKotor v0.4.3 — more apks welcome

A compatibility release. The port now runs with the 1.0.7 / 1.0.71 Android APK as well as 1.0.10, and the README says which APK versions work.

## What changed

- **The 1.0.7 / 1.0.71 APK now works.** Its game libraries are an older build than 1.0.10's. The loader now provides the five extra functions that build needs, and finds its movie code by content instead of at a fixed address. Tested on hardware: main menu, saves, the Equip and Abilities screens, movies with sound, and the MODS menu.

- **1.0.9 build 54 is confirmed to work.** Its game libraries are byte-for-byte the same as 1.0.10's.

- **Which APK do I have?** Look inside `lib/armeabi-v7a/` in the APK. If it has `libfmod.so`, it works. If it has `libfmodex.so` and `libgnustl_shared.so` instead, it is the Amazon Underground build, which does not. The README has the full table, and `tools/check_apk.py` checks an APK on a PC without needing a Vita.

- **The mod-set menu now says "MODS button"** instead of "Google Play button".

- **A rare sound-related crash is closed off.** One of the loader's diagnostic hooks could crash if the game ever played a sound that had not been fully set up. That hook is now skipped. Nothing you hear changes.

- **KOTOR-nolog.vpk**: an optional build with diagnostic logging disabled. Install it in place of `KOTOR.vpk` if you prefer not to have a log file written.

## Updating

Install `KOTOR.vpk` over your current one. Your files in `ux0:data/kotor/`, your saves and your mods stay as they are. To switch APK versions, replace the four `.so` files in `ux0:data/kotor/` with the ones from the other APK.

## Honest limits

- **The Amazon Underground APK (1.0.9, `com.aspyr.swkotor.underground`) does not work.** It is an older build with a different sound engine and C++ runtime, and supporting it would be a separate port. Use the Google Play APK.

- **1.0.71 was tested for one session, not a full playthrough.** The parts the port changes were checked, but a long run on it has not been done yet.

- **The rare crash after an area-change auto-save** (issue #12) is still open.

## Everything else from v0.4.2 still applies

Griff spawns in the Sand People Enclave, texture quality is picked from the MODS button, busy areas have 96 sound channels, and frames are locked to 30 fps.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own.

## Something broken?

Open an issue with `ux0:data/kotor/log.txt` attached, and say where in the game it happened.
