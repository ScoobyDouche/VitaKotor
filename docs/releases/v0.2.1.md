# VitaKotor v0.2.1 — fan translations

You can now play in a fan translation without touching the game files. Put the translation in its own folder on the memory card and it appears in the language list next to the five built-in languages.

This came out of issue #8.

## What changed

- **Fan translations show up in the language list.** Make a folder named after the language, such as `ux0:data/kotor/translations/Polski/`, and put the translation's `tv_dialog.tlk` (or `dialog.tlk`) in it. Press L while the game is starting and pick it.

- **The choice is remembered.** It is saved as `Translation=Polski` in `swkotor.ini`. Picking one of the built-in languages again switches it off.

- **The boot-screen tips use the translation too.**

- **Any other file in the folder replaces the game's file of the same name.** For example, a translation can ship its own main-menu button pictures.

- **The log tells you whether a translation fits.** Look for `[tr]` in `ux0:data/kotor/log.txt`. It says how many entries the file has; the game's own tables have 49,265. If the numbers differ, the file was made for another edition of the game.

## Honest limits

- **Western European letters only.** Accented Latin text shows up fine, but Cyrillic, Greek and other scripts come out as the wrong letters. Work on that is started but not finished.

- **The main-menu buttons stay in English** unless the translation brings its own pictures, because they are images, not text.

- **Voice-over is English,** as it was in the retail releases.

- **Don't repack or edit the OBB files.** The card folder is read first, so there is no need to, and a repacked OBB can stop the game from starting.

## Everything else from v0.2.0 still applies

Cutscenes play, the buttons and the touchscreen both work, and the minimap and character screens draw correctly. Combat, dialogue, inventory, saves, the swoop race and Force powers all work.

Still outstanding: distant sounds are too loud, shiny armour reflects the room, geometry can come apart late in a long session, and there are no trophies.

## You need your own copy of the game

This is a loader, not a game. It needs the Android release's `main` and `patch` `.obb` files, which you must own.

## Something broken?

Open an issue with `ux0:data/kotor/log.txt` attached.
